Los estudiantes podrán: usar WebWave, JDoodle y GitHub para separar Frontend/Backend/DB e identificar APIs externas para representar interacciones en un diagrama y comprender el pensamiento sistémico y el control humano sobre decisiones estratégicas.

📊 Diapositiva 3: Brain Spark

1. 💬 Pide a XOLO que te ayude a crear:

"Con Vibe Coding, ayúdame a convertir mi idea en un diagrama de arquitectura comentado: define el usuario principal, el flujo central y qué datos se almacenan. Luego guía mi decisión de: (1) componentes mínimos, (2) una API externa útil, (3) riesgos (privacidad, dependencia). Ejecuta: entrega el guion de mi diagrama (qué dibujo y qué comentario pongo en cada bloque) y cómo lo presentaré como pitch técnico."

2. 🔬 Experimenta y descubre con tu arquitectura:

  • ¿El flujo de datos entre el usuario y la base de datos es lógico y directo?
  • ¿Qué pasaría con la privacidad de los usuarios si la API externa falla o es insegura?
  • ¿Funciona igual tu arquitectura si decides cambiar el Frontend de WebWave a otra plataforma?
  • ¿Cómo ayuda el pensamiento sistémico a prever problemas antes de escribir la primera línea de código?
  • ¿Por qué es fundamental que el humano mantenga el control estratégico sobre las decisiones que propone la IA?

¡Es hora de crear! Vamos a transformar sus ideas en planos reales. Usen el prompt que ven en pantalla para que XOLO los guíe en la creación de un diagrama de arquitectura. Imaginen, por ejemplo, una app que use una API de mapas para ayudar a personas a encontrar centros de reciclaje cercanos. XOLO les dará el 'Vibe' y las indicaciones para diseñar su diagrama. Dibújenlo en papel o en una herramienta digital como WebWave, y añadan comentarios que expliquen cada componente. No se queden solo con lo que les diga, cuestionen y ajusten. Si tienen dudas sobre cómo conectar una API o qué base de datos usar, pregúntenle a XOLO, él los ayudará a depurar su lógica arquitectónica.

📊 Diapositiva 4: Think-Pair-Share

🤔 THINK (30 seg)

Reflexión individual: ¿Qué partes de tu arquitectura conectan mejor? ¿Qué te sorprendió de la función de las APIs?

Con otra pareja: Presenten su diagrama y expliquen su experiencia

Frase guía: "Mi arquitectura conecta el Frontend con una API de servicios externos. Me sorprendió que la base de datos fuera tan importante para la persistencia."
